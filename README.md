# Hackinity — launch page

A buildless Arabic RTL launch page for GitHub Pages. Upload the contents of this folder to the published branch, keeping `index.html` at its root. No package installation or build step is required.

## Contact details

Edit `config.js` with your actual Telegram URL and email address. Empty or invalid values keep the corresponding link hidden. No account, email, subscription form or backend is fabricated.

## Design

- Near-black `#080b09`, text `#f0f3eb`, secondary text `#a4afa5`, brand lime `#c8ff1b`.
- Desktop: text on the right, animated mark on the left. Mobile: mark followed by text.
- One concise sentence introduces labs, paths and practical certificates. The header uses a full vector symbol and outlined wordmark aligned to the left.
- The SVG introduction takes 2.7 seconds. The completed angular infinity changes into the supplied final geometry, with a slash and fragments. The introduction plays automatically. On-screen playback controls are omitted. A stronger sliced cyan/lime glitch affects only سحرك for a short burst every 5.5 seconds. Reduced-motion mode disables it.
- Reduced-motion preference shows the final mark immediately. Animation pauses offscreen and when the document is hidden.
- All assets use relative paths. Contact settings are local. No tracking, remote fonts or dependencies.

## Verification

JavaScript syntax, local asset references, contact configuration, final SVG geometry, animation completion, pause/replay and reduced-motion logic were checked programmatically. Foreground/background color contrast was calculated. Browser rendering at 390px and 1440px could not be checked in the available environment; responsive CSS is provided but not claimed to be visually verified.
